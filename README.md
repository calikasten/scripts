# Scripts
Scripts that automate stuff on MacOS. Last Updated 06/12/2025.

## Note Taking
[Format Fathom Notes](https://github.com/calikasten/scripts/blob/master/Format%20Fathom%20Notes.scpt) <br>
Automatically formats the copied summary from [Fathom](https://fathom.video/) meeting notes into preferred styling.

## Utilities
[Connect to AirPods](https://github.com/calikasten/scripts/blob/master/Connect%20to%20AirPods.sh) <br>
Uses [blueutil](https://github.com/toy/blueutil) to force connect to AirPod's MAC address.
