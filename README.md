# Scripts
Scripts that automate stuff on MacOS. Last Updated 04/29/2026.

## Communication
[Email Current URL](https://github.com/calikasten/scripts/blob/main/scripts/email-current-url.scpt) <br>
Automatically copies the URL of the active tab from a web browser to the clipboard and sends an email with that URL in the body of the email.

## Utilities
[Connect to AirPods](https://github.com/calikasten/scripts/blob/main/scripts/connect-to-airpods.sh) <br>
Uses [blueutil](https://github.com/toy/blueutil) to force connect to AirPod's MAC address.
